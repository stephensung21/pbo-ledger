# Pho Ledger

A one-page site for rating pho restaurants.

- **Six scores per bowl (1–10):** Broth, Noodles, Meat & protein, Herbs & garnish, Value, Portion. The overall score is a weighted average: broth counts 3×, noodles and meat 1.5×, the rest 1×.
- **Rankings** by overall score, any single category, or most recent visit.
- **Map** of every restaurant (OpenStreetMap), with address search and click-to-place pins.
- **Export / Import** ratings as JSON. Ratings are stored in your browser's local storage, so use Export to back them up or move them between devices.

No build step: `index.html` is the whole site. Hosted with GitHub Pages from the `main` branch.
